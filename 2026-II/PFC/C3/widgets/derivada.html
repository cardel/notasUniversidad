derivada: calcule con la fórmula

derivada(f, dx) devuelve la función x => (f(x + dx) - f(x)) / dx. Para cube en x = 2 la derivada exacta es 12, y lo que devuelve la función fabricada no es 12: se le puede calcular exactamente cuánto se aleja. Haga la cuenta antes de ver lo que imprime el programa.

def derivada(f: Double => Double, dx: Double): Double => Double =
(x: Double) => (f(x + dx) - f(x)) / dx
def cube(x: Double): Double = x * x * x

1. Llene la tabla con la expansión

Con f = cube y x = 2: ((2 + dx)³ − 8) / dx = (8 + 12·dx + 6·dx² + dx³ − 8) / dx = 12 + 6·dx + dx².

Lo impreso no coincide exactamente con la fórmula en los últimos decimales: es la aritmética de punto flotante, que no representa 0.1 de forma exacta. El error de la aproximación, 6·dx + dx², sí es el que la fórmula dice.

3. Lo que se lleva de aquí

derivada recibe una función y devuelve otra del mismo tipo, y por eso se puede aplicar a su propio resultado: la segunda derivada no necesita código nuevo. Lo que sí cambia es el error, que se acumula en cada aplicación. La expansión 12 + 6·dx + dx² dice algo que ninguna corrida dice sola: el error es lineal en dx, así que dividir dx por 10 divide el error por 10.
