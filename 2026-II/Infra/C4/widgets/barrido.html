Hilos que no aceleran y una suma 112 veces más rápida

El mismo trabajo, sumar cien millones de enteros, corrido de dos maneras: con una lista de Python recorrida por índices y con un arreglo de NumPy sumado por segmentos, cada una con 1, 2, 4 y hasta 16 hilos. Escriba cuánto tarda cada versión antes de destapar las tablas medidas y después compare las dos escalas de tiempo.

1. El programa

Con la lista de Python, cada hilo recorre su tramo de índices y acumula en una variable local:

1import threading, time
2
3size = 100_000_000
4l = [2] * size
5
6def sumar(lst, ini, fin):
7 s = 0
8 for i in range(ini, fin):
9 s += lst[i]
10 return s

Con NumPy cambian tres líneas, las marcadas en amarillo:

1import threading, time
2import numpy as np
3
4size = 100_000_000
5l = np.ones(size) * 2
6
7def sumar(lst, ini, fin):
8 return lst[ini:fin].sum() # suma vectorizada del segmento
El lanzamiento es idéntico en las dos versiones: un recorrido por 2, 4, 6, 8, 10, 12, 14 y 16 hilos que arma cada uno con t = threading.Thread(target=sumar, args=(l, ini, fin)), le entrega size // num_hilos elementos y espera a todos con join. El tiempo se toma con perf_counter antes de crear el primer hilo y después del último join. Las mediciones se tomaron en un AMD Ryzen 5 3600, 6 núcleos y 12 hilos de hardware, 32 GB de memoria, con Python 3.14 sobre Linux.

2. Antes de ver la tabla

Con la lista de Python, ¿cuántos segundos tarda la suma con 4 hilos? Dos decimales.
Con NumPy y un solo hilo, ¿cuántos milisegundos tarda?
Un hilo con la lista tardó 5,05 s. Los cuatro hilos se reparten el mismo trabajo, veinticinco millones de sumas cada uno, y corren sobre una máquina con 6 núcleos libres.

4. Por qué NumPy sí escala

Con la lista, agregar hilos subió el tiempo; con el arreglo, lo bajó a la mitad. El programa que los lanza es el mismo.

5. Por qué se estanca en 0,024 s

De 2 a 16 hilos el tiempo con NumPy pasa de 0,027 a 0,024 s: ocho veces más hilos para bajar 3 ms.

El arreglo ocupa unos 800 MB y la suma los recorre de punta a punta: cada hilo pide memoria continuamente y el ancho de banda es el mismo para todos.
