Resolver un problema con bisección, paso a paso

Un problema de juez en línea que nadie vio en clase, atacado con el método completo: entender qué se pide, nombrar la función objetivo, demostrar que es monótona, acotar el rango, decidir si la solución existe, fijar la tolerancia y recién ahí escribir código. Cada tarjeta se abre cuando la anterior queda resuelta.

1. El problema

UVa 10341 — Solve It.
https://onlinejudge.org/external/103/10341.pdf

Resuelva la ecuación

p·e⁻ˣ + q·sen(x) + r·cos(x) + s·tan(x) + t·x² + u = 0

donde 0 ≤ x ≤ 1.

Entrada. Varios casos de prueba hasta EOF. Cada caso trae seis enteros en una línea: p q r s t u, con 0 ≤ p, r ≤ 20 y −20 ≤ q, s, t ≤ 0.

Salida. Por cada caso, el valor de x con 4 decimales, o la cadena No solution cuando corresponda.

Fíjese en las restricciones de los coeficientes antes de seguir: parecen un detalle de formato y son el corazón del problema.

4. ¿Es monótona? La parte que no se asume

La bisección solo funciona si f es monótona en el rango. Nadie lo dice en el enunciado: hay que demostrarlo, y la prueba se arma término a término. Para cada uno, derive y decida qué hace en [0, 1] con la restricción que le impone el enunciado.

Los seis términos tienen derivada ≤ 0 en [0, 1], así que f′(x) ≤ 0: la función decrece en todo el rango. Ahí está la licencia para aplicar bisección. Y note de dónde salió: de las restricciones sobre los coeficientes, esas que parecían formato. Si el enunciado permitiera t > 0, el término t·x² subiría, la monotonía se caería y este problema pediría otra técnica.

5. El rango y la pregunta que casi nadie hace

El rango viene regalado: [0, 1]. Pero el enunciado admite responder No solution, así que hay algo más que comprobar. ¿Cómo se decide si la solución existe?

El segundo caso es el que enseña: f(0) y f(1) son los dos positivos, la curva nunca cruza el cero dentro del rango y la respuesta no es un número.

El juez pide 4 decimales. ¿Qué ε conviene?

8. El código, ya con todo decidido

Cada línea sale de una decisión de las tarjetas anteriores, no de una plantilla copiada.

import math

def f(p, q, r, s, t, u, x):
    # El lado izquierdo de la ecuacion, evaluado en x
    return (p * math.exp(-x) + q * math.sin(x) + r * math.cos(x) +
            s * math.tan(x) + t * x * x + u)

def resolver(p, q, r, s, t, u, eps):
    # f decrece en [0, 1]: hay raiz solo si el cero queda encerrado
    if f(p, q, r, s, t, u, 0) < 0 or f(p, q, r, s, t, u, 1) > 0:
        resultado = None
    else:
        a = 0.0
        b = 1.0
        while b - a > eps:
            mitad = (a + b) / 2
            if f(p, q, r, s, t, u, mitad) > 0:
                a = mitad
            else:
                b = mitad
        resultado = (a + b) / 2
    return resultado

La comparación de la línea del if interno va al revés que la de la clase, y esa inversión es justo lo que la tarjeta 4 autorizó: f decrece, así que un valor positivo en la mitad significa que la raíz está a la derecha.
