¿Compila este datatype?

Nueve declaraciones con define-datatype, unas bien y otras con el error que aparece cada semestre, y después siete expresiones sobre un datatype ya cargado, para predecir qué acepta el constructor y qué rechaza. Lo que se juzga es lo que DrRacket responde, con sus mensajes.

Los dos bloques, resueltos

Lo que se rechaza al compilar y lo que se rechaza al construir:

Lo detectaQuéEl mensaje
el compiladoruna variante o el predicado con el nombre del tipoidentifier already defined
el compiladorun campo sin predicado o sin paréntesisexpected a field name followed by a predicate
el compiladordos campos o dos variantes igualesduplicate
el constructorun valor que no cumple el predicado del campobad value for … field
nadieun símbolo válido con un significado que no existe—
define-datatype define nombres y el constructor revisa predicados. Lo que cae fuera de esas dos cosas —una dirección que no existe, una lista donde iba un comando— solo se atrapa si el tipo lo dice: un tipo aparte para las direcciones, list-of donde va una lista. Cuanto más dice el tipo, menos programas mal formados llegan a existir.
