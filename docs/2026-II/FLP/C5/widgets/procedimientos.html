Procedimientos en acción

Cuatro programas con procedimientos: uno aplicado dos veces, uno que recibe otro como argumento, uno que devuelve otro y uno cuyo cuerpo menciona una variable que cambia después. Se predice el valor y las cuentas, y al comprobar se abren la traza, la cadena de ambientes y cada clausura con el ambiente que capturó.

El lenguaje y la escritura son los del interpretador de la sesión: números, variables, true y false, las primitivas escritas antes del paréntesis —+(e,e), -(e,e), *(e,e), add1(e), sub1(e), >(e,e), <(e,e), ==(e,e)—, if e then e else e, let id = e … in e, proc(id, …) cuerpo y la aplicación (rator rand …). El ambiente inicial liga x = 4, y = 2, z = 5 sobre otro eslabón con a = 4, b = 5, c = 6. La página hace lo mismo que el interpretador en Racket, con sus verificaciones: la prueba del if con boolean?, el operador de una aplicación con procval? y la cantidad de argumentos contra la de parámetros.
