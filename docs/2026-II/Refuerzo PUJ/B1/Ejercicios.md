# Ejercicios · Refuerzo PUJ 17 de octubre

Siete actividades para trabajar en el navegador lo que se vio en la
[sesión del 17 de octubre](./17%20de%20octubre.%20Estructuras%20y%20un%20recorrido.md). Las tres primeras
recorren paso a paso los problemas de clase; las dos siguientes repasan cuánto
cuesta cada operación sobre un arreglo y cómo se guarda una matriz en memoria.
Las dos últimas son de lógica: pasar frases a fórmulas con cuantificadores y
decidir equivalencias con la tabla de verdad.

## [maximo-acumulado](../../../actividades/estructuras-de-datos/recorridos-arreglos/maximo-acumulado.html){ target=_blank rel=noopener }

UVa 11078: llevar el mayor valor que quedó atrás para obtener la mayor
diferencia $A[i] - A[j]$, con $i < j$, en un solo recorrido.

## [mejor-tramo](../../../actividades/estructuras-de-datos/recorridos-arreglos/mejor-tramo.html){ target=_blank rel=noopener }

UVa 507: decidir en cada posición si el tramo sigue o se reinicia, con el
desempate por el tramo más largo y después por el que empieza antes.

## [acumulados](../../../actividades/estructuras-de-datos/matrices/acumulados.html){ target=_blank rel=noopener }

UVa 108: con la tabla de acumulados de una matriz, obtener la suma de
cualquier rectángulo con cuatro lecturas.

## [costos](../../../actividades/estructuras-de-datos/stl-contenedores/costos.html){ target=_blank rel=noopener }

Contar cuántos elementos se corren con un `insert` en un vector, y lo que
cuestan `binary_search` y `sort`.

## [rowmajor](../../../actividades/estructuras-de-datos/punteros-arreglos/rowmajor.html){ target=_blank rel=noopener }

Ubicar en memoria las casillas de una matriz guardada fila tras fila, a partir
de su dirección de inicio y del tamaño de cada entero.

## [traducir](../../../actividades/ayg-puj/logica/traducir.html){ target=_blank rel=noopener }

Doce frases sobre arreglos, estudiantes y la definición de $O$, cada una con
cuatro fórmulas candidatas; una opción errada muestra un caso donde falla.

## [equivalencias](../../../actividades/ayg-puj/logica/equivalencias.html){ target=_blank rel=noopener }

Decidir si dos fórmulas son equivalentes, completar su tabla de verdad y
marcar la fila que las separa; también genera la tabla de un par propio.
