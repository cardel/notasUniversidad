sumador: una función que fabrica funciones

sumador(n) no suma nada: devuelve la función sumar n. Esa función recuerda su n y se puede aplicar, guardar en un val o pasar a otra función. Lo que hay que ver en la sustitución es cuándo se fabrica cada función y qué n quedó adentro.

def sumador(n: Int): Int => Int = (x: Int) => x + n
def aplicaDos(f: Int => Int, x: Int): Int = f(f(x))

3. Lo que se lleva de aquí

En sumador(s(1)) hay dos funciones fabricadas con dos n distintos, y la segunda se construye con el resultado de aplicar la primera. Nada de eso se ve en el código: se ve en la sustitución, que por valor reduce s(1) antes de llamar a sumador. Y en aplicaDos(sumador(3), 4) la función se fabrica una vez y se usa dos: fabricar y aplicar son pasos separados.
