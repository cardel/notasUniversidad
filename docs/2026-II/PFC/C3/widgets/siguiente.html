siguiente: elija el paso que sigue

El modelo de sustitución reduce una cosa por paso, y por valor el orden no es opcional: los argumentos se reducen antes de entrar y el operando izquierdo antes que la llamada de la derecha. Aquí la reducción de suma(cuadrado, suc, 1, 3) no se muestra: se construye. En cada paso hay tres expresiones y solo una es la que sigue.

def suma(f: Int => Int, prox: Int => Int, a: Int, b: Int): Int =
if (a > b) 0
else f(a) + suma(f, prox, prox(a), b)
def cuadrado(x: Int): Int = x * x
def suc(x: Int): Int = x + 1

Tres de los distractores dan otro número: aplicar f al término siguiente, avanzar b en vez de a, y cerrar con 1 en lugar de 0. Los otros no cambian el valor y por eso son más difíciles de ver: sustituir un cuerpo sin reducir antes sus argumentos, o cerrar una suma de afuera cuando la de adentro todavía no tiene dos valores. El compilador no avisa de ninguno; solo la traza los muestra.
