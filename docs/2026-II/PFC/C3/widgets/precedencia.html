precedencia: hasta dónde llega el cuerpo

El cuerpo de un literal x => … se extiende hasta donde alcance, y dentro de él mandan las reglas de siempre: el * y el / antes que el + y el -, y la división entre enteros descarta el resto. Un literal que parece un promedio puede no serlo. Prediga el valor y después siga la reducción operación por operación.

(x, y) => x + y / 2 compila, tiene el tipo correcto y devuelve un entero: nada avisa. Solo la reducción muestra que divide primero. Cuando un literal tiene más de una operación, los paréntesis no son estilo: son la única forma de decir qué se hace primero, igual que en cualquier expresión.
