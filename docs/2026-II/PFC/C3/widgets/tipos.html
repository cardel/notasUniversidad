tipos: qué tipo tiene cada expresión

Con varios grupos de paréntesis, llenar un grupo no da un número: da una función que espera los grupos que faltan. El tipo de la expresión dice exactamente qué falta. Cinco expresiones, cuatro tipos cada una, y solo uno es el que el compilador acepta.

def suma4(f: Int => Int)(prox: Int => Int)(a: Int, b: Int): Int = ...
def sumaC(a: Int)(b: Int): Int = a + b
def derivada(f: Double => Double, dx: Double): Double => Double = ...
def sumador(n: Int): Int => Int = (x: Int) => x + n

7. Lo que se lleva de aquí

Cada grupo que se llena quita una flecha del tipo, de izquierda a derecha. suma4 entera es (Int => Int) => (Int => Int) => (Int, Int) => Int; con un grupo queda (Int => Int) => (Int, Int) => Int; con dos, (Int, Int) => Int; con los tres, Int. El orden de los grupos decide qué se puede fijar sin escribir un literal, y por eso restaC(5) fija el minuendo y no el sustraendo.
