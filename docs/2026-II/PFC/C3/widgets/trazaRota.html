trazaRota: encuentre el paso equivocado

Tres trazas de suma(x => x + 1, x => x + 2, 1, 7) escritas por alguien más. Dos salieron de versiones de suma que compilan y dan un número equivocado; una está bien. Cada traza es consistente consigo misma después del error, así que el total no delata nada: hay que leer paso por paso. Marque el primer paso equivocado, o diga que no hay ninguno, y nombre la versión que lo produjo.

def suma(f: Int => Int, prox: Int => Int, a: Int, b: Int): Int =
if (a > b) 0
else f(a) + suma(f, prox, prox(a), b)
def sumaSinProx(f: Int => Int, prox: Int => Int, a: Int, b: Int): Int =
if (a > b) 0 else f(a) + sumaSinProx(f, prox, a + 1, b)
def sumaBaseUno(f: Int => Int, prox: Int => Int, a: Int, b: Int): Int =
if (a > b) 1 else f(a) + sumaBaseUno(f, prox, prox(a), b)

Una traza equivocada no se ve en el total: 35 y 21 son números tan creíbles como 20. Se ve en dos sitios concretos. El a que entra en cada paso tiene que ser el prox del anterior, y el valor con que cierra la última llamada tiene que ser el neutro de la operación. Esos dos sitios son justamente los dos parámetros que suma deja abiertos: quien los revisa, revisa la función entera.
