esqueleto: qué cambia entre tres sumas

sumaEnteros, sumaCuadrados y sumaPasoDos comparten la condición de parada, el cero y la llamada recursiva. Solo cambian dos cosas: qué se hace con cada término y cuál es el siguiente. Esas dos cosas son los parámetros f y prox de suma. Aquí las tres sumas vienen escritas en matemáticas, no en código: hay que leer cuál es el término y cuál el avance.

1. Escoja f y prox para cada suma

def suma(f: Int => Int, prox: Int => Int, a: Int, b: Int): Int =
if (a > b) 0
else f(a) + suma(f, prox, prox(a), b)

2. Lo que se lleva de aquí

Las tres sumas son la misma función con dos argumentos distintos. Eso es lo que hace una función de alto orden: recibe las dos piezas que cambian y se queda con el esqueleto. La tercera suma muestra que prox no tiene por qué sumar: el siguiente término puede ser el doble, y suma no se entera.

Y la trampa que más se repite: x => x + 3 puesto como f suma 3 a cada término en lugar de avanzar de tres en tres. Da un número, compila, y está mal.
