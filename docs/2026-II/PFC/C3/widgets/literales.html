literales: qué hace cada literal dentro de suma

Un literal de función no se entiende solo: se entiende por lo que suma hace con él. Puesto como f transforma cada término; puesto como prox decide cuál viene, y por eso puede hacer que la suma sea 0, que dé un número inesperado o que no termine. Cuatro preguntas; en todas hay que calcular.

def suma(f: Int => Int, prox: Int => Int, a: Int, b: Int): Int =
if (a > b) 0
else f(a) + suma(f, prox, prox(a), b)

5. Lo que se lleva de aquí

El literal x => x + 1 aparece dos veces en estas preguntas y no significa lo mismo: como f corre cada término, como prox los recorre de uno en uno. No hay nada en el literal que diga cuál de los dos es; lo dice la posición en la llamada. Y un prox que no avanza no produce un error de tipos ni un resultado raro: produce una pila llena, porque cada vuelta de suma deja una suma esperando.
