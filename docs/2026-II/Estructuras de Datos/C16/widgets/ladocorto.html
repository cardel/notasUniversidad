4. La cota de nodoEn

Escogiendo el lado, ¿en qué queda la cota de nodoEn sobre una lista de n elementos?

Lo que quedó

El contador y el enlace hacia atrás compran escoger el sentido: el peor caso baja de n - 1 pasos a ⌈n/2⌉ y el total de un recorrido por posiciones baja casi a la mitad. La cota asintótica no se mueve, porque ⌈n/2⌉ crece como n; lo que se gana es una constante, y eso sí se mide en el reloj.
