string

Cuatro expresiones sobre cadenas. Escriba lo que imprime printf("%d", ...) con cada una: 1 o 0 para las comparaciones, el número para el tamaño.

1. Al revés

alReves("anilina") == "anilina"

2. Menor, letra a letra

string("mapa") < string("mano")

3. El prefijo

string("cola") < string("colar")

4. Concatenar y medir

(string("pila") + " y cola").size()

Lo que quedó

string es un vector de caracteres con dos cosas propias: el + concatena y el < ordena como el diccionario, letra a letra y con el prefijo primero. Todo lo demás (size, [], at, push_back) es el mismo contrato de vector.
