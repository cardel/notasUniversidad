Lo que cobra cada operación

Dos cuentas sobre un vector guardado como arreglo que crece: cuántos elementos hay que correr.

1. Un insert en la mitad

Un vector con 6 elementos recibe v.insert(v.begin() + 2, x). ¿Cuántos elementos se corren de lugar?

2. revertir con insert al frente

revertir recorre un vector de 5 elementos y hace r.insert(r.begin(), l[p]) con cada uno. Sumando todas las inserciones, ¿cuántos elementos se corren en total?

Lo que quedó

Para n elementos, revertir con insert al frente corre 0 + 1 + … + (n − 1) = n(n − 1)/2: del orden de n². Con push_back desde el final, del orden de n. Esa tabla de costos es la que se va a demostrar cuando el vector se construya a mano.
