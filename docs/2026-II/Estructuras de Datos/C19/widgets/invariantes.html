Lo que sostiene el ciclo de particionar

El arreglo de entrada es ⟨6, 1, 7, 3, 8, 2, 4⟩ con ini = 0 y fin = 6, así que x = 4 y M₀ = {{1, 2, 3, 4, 6, 7, 8}}. Abajo hay seis estados anotados al evaluar la condición del while. En cada uno falla a lo sumo un invariante.

Los cinco invariantes

I1ini − 1 ≤ i < j ≤ fin
I2∀k, ini ≤ k ≤ i: a[k] ≤ x
I3∀k, i + 1 ≤ k ≤ j − 1: a[k] > x
I4a[fin] = x
I5{{ a[k] : ini ≤ k ≤ fin }} = M₀
Un rango vacío, como ini ≤ k ≤ i con i = ini − 1, hace que la fórmula se cumpla sin casos que revisar.

Lo que quedó

Cada invariante cuida una pieza distinta del estado: I1 los índices, I2 e I3 las dos zonas ya revisadas, I4 el pivote y I5 los valores. Un error en el código rompe una pieza concreta: avanzar i sin intercambiar rompe I2, dejar pasar un valor pequeño rompe I3, tocar fin dentro del ciclo rompe I4 y un intercambio sin temporal rompe I5. Por eso la demostración revisa los cinco en cada vuelta.
