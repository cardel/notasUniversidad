Ejercicios sobre las implementaciones: rotar la cola

Una operación nueva para la cola sobre nodos, la que guarda cabeza, ultimo y n: rotar() pasa el frente al final sin reservar ni liberar nodos, solo cambiando punteros. La cola de prueba es ⟨8, 3, 6, 1⟩, del frente al final.

1. Tres rotaciones

// exige !vacia()
void rotar() {
  assert(!vacia());
  if (cabeza != ultimo) {
    Nodo *primero = cabeza;
    cabeza = cabeza->siguiente;
    primero->siguiente = NULL;
    ultimo->siguiente = primero;
    ultimo = primero;
  }
}

Después de llamar tres veces a rotar(), ¿cómo queda la cola del frente al final?

Lo que quedó

rotar mueve un nodo de un extremo al otro con cuatro escrituras de puntero: Θ(1) en tiempo y Θ(1) en espacio aparte, sin reservar ni liberar memoria. Escrita con el contrato, encolar(frente()) seguido de desencolar(), también es Θ(1), pero reserva un nodo y libera otro en cada llamada. Con punteros, el orden de las asignaciones decide: un enlace se lee antes de cortarlo, y el caso de un solo elemento, donde cabeza y ultimo son el mismo nodo, se revisa aparte.
