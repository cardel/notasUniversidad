Un dato y una dirección

Cuatro nodos enlazados a mano con los datos 4, 1, 6 y 8. El último apunta a NULL.

1. Qué imprime el recorrido

2. Liberar la cadena

Las dos versiones recorren la cadena llamando a delete una vez por nodo. Una de las dos deja de funcionar.

Lo que quedó

La condición del ciclo decide dónde se detiene el recorrido: con actual != NULL se visitan todos los nodos, y con actual->siguiente != NULL se para en el penúltimo. Y al liberar, la dirección del siguiente se guarda antes del delete: después del delete el nodo ya no se puede leer.
