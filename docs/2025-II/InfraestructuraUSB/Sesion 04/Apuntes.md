Los contenedores son entornos ligeros y portables que permiten ejecutar aplicaciones de manera aislada junto con todas sus dependencias. Docker es una plataforma que permite crear, desplegar y gestionar contenedores de forma sencilla.

### Características principales

- **Aislamiento:** Cada contenedor funciona de manera independiente, sin interferir con otros.
- **Ligereza:** Usan menos recursos que las máquinas virtuales, ya que comparten el kernel del sistema operativo.
- **Portabilidad:** Se pueden ejecutar en cualquier entorno que tenga Docker instalado, sin importar el sistema operativo subyacente.
- **Rapidez:** El inicio de los contenedores es casi instantáneo.

### Casos de uso

- Despliegue de aplicaciones en ambientes de desarrollo, prueba y producción.
- Microservicios que requieren entornos independientes.
- Integración continua y entrega continua (CI/CD).
