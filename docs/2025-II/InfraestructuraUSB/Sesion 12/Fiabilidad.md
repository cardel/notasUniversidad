- Capacidad de un sistema de ofrecer funcionalidad a partir de tos sus componentes
- Probabilidad de que el sistema funciones durante un periodo específico
- Tiempo promedio de errores (MTBF) tiempo total en servicio - cantidad de errores
- Numero 9, cinco 9, significa 99.999%

# Alta disponibilidad

- Sistema puede soportar cierto de grado de degradación (errores o eventos inesperados) y aún funcionar
- Requiere mínima intervención human

# Factores

- Tolerancia a errores: Redundancia
- Escalabilidad: Elasticidad de la capacidad
- Recuperación de errores: Procesos y políticas para recuperarse de errores
