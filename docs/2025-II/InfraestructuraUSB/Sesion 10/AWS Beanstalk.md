# Introducción

Es un servicio para desplegar aplicaciones WEB

Es un servicio en el cual AWS administra lo relativo a la aprovisionamiento (infraestructura, carga, escalado, etc)

No se cobra por el servicio si no por lo servicios subyacentes que se utilizan

Permite gestionar aplicaciones multiples frameworks y sólo consiste en cargar el código o el contenedor y configurar la ejecución

# Características

- Sencillo de usar 
- Los desarrolladores se concentra en el código
- La optimización depende del código, pero si es de infraestructura no es posible
- Se puede configurar para gestionar el uso de recursos por parte de la aplicación, sin embargo, esto es realizado por AWS
