# Resumen

1. Funciones de alto orden: Las funciones son valores (los cuales podemos evaluar) se trabajan igual que los otros tipos
2. Currificación: Es una técnica que permite convertir funciones de múltiples parámetros a uno solo
3. Recursión: lineal, de cola y de árbol
