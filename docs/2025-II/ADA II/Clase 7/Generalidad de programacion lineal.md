
Problema de programación lineal

1. Función a maximizar o minimizar lineal
2. Sujeto a restricciones lineales, en las cuales se realiza una inequidad o equidad hacia un valor constante f(x) <= b f(x) = b, f(x)>=b ...
3. Formas
	1. Holgura: Maximización sujeto a igualdades lineales
	2. Estándar: Maximización sujeto a desigualdades lineales

```
x variables de decisión
max f(x)
sujeto a:
	f1(x) <= b1
	f2(x) <= b2
	...
	fn(x) <= bn
	x >= 0 //No negatividad
```

# Tipos

1. 2 variables plano x,y
2. >2 variables hiperplano (simplex)
