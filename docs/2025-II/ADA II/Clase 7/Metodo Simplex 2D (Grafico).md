Esto lo aplicamos en problemas que tiene dos variables de decisión

```
3xe + 2xi

xe + 2xi <= 6
2xe + xi <= 8
-xe + xi <= 1
xi <= 2
xe,xi >= 0
```

Notese que el vector (0,0) = (xe,xi) es una **solución factible**

En general el método grafico:

1. Trazar las restricciones no negatividad (cuadrante positivo)
2. Trazar las restricciones <= (si tienen >= tener en cuenta que es el sentido contrario)
3. Los puntos factibles están en las intersecciones de las restricciones evaluar la función alli para encontrar el máximo
