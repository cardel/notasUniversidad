
Es un método de demostración para teoremas $\forall n P(n)$ por ejemplo

1. Para todo n, 2*n es par
2. 1+2+3+...+n = $\frac{n*(n+1)}{2}$

El metodo de demostración consiste en:

1. Demostrar el caso base P(1) No es que n valga 1, si no que es el valor donde vemos el caso base
2. $P(k) \implies P(k+1)$ Esto quiere decir que asumo P(k) como verdad y voy a demostrar a partir de el siguiente
