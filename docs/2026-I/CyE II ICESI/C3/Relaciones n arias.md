
Las relaciones n-arias permiten obtener relaciones a partir del producto cartesiano de multiples conjuntos, a partir de esto podemos representar lo que son las bases de datos

A = nombres
B = edad
C = profesiones
D = cedulas


| Nombre | Edad | Profesion   | Cedula |
| ------ | ---- | ----------- | ------ |
| Juan   | 29   | Psicologo/a | 1234   |
| Maria  | 91   | Psicologo/a | 2323   |
| Pedro  | 88   | Policia     | 2331   |
Una llave primaria consiste en que solo existe una ocurrencia dentro de la relación de cada conjunto

Suponiendo que los datos no cambian entonces podemos decir

- Nombre puede ser una llave primaria, porque no se repite

- Edad puede ser una llave primaria

- Cedula puede ser una llave primaria

Un operador de seleccion permite obtener los elementos de una Relacion n aria que cumplen una condicion, ejemplo edad < 50
