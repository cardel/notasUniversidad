
# Como vamos

1. Estilo de programación funcional.
	1. Variables inmutables
	2. Funciones de alto orden
	3. Recursión como método de solución de problemas
	4. Toda expresión debe resolverse como un valor
2. Recursión lineal
	1. Caso base: Tiene respuesta inmediata
	2. Caso recusivo: Compone la solución  y nos lleva al caso base.
3. Recursión estructural listas
	1. Vacia o Empty, caso base
	2. Caso no vacio: Cabeza y cola. Cola tiene que ser una lista
4. Estrategias de evaluación
	1. Evaluamos a izquierda a derecha
	2. CBV por defecto: los argumentos se evaluan de inmediato
	3. CVN (nombre) cuando se necesitan
