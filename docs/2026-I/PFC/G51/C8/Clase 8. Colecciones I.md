# Limitacion de las listas

1. Las listas son una estructura recursiva
	1. Caso base: List()
	2. Caso recursivo: valor (head), lista (cola)
2. Por esta razón el costo de acceder a un elemento cualquiera es O(n)
3. No son apropiadas para operaciones que requieren un acceso alatorio (desordenado de los elemnentos)
