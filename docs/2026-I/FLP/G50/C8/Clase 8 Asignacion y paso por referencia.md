
# Como vamos

hasta ahora hemos visto como se construye un lenguaje funcional (valores inmutables)

1. Primitivas
2. Ligaduras (let)
3. Procedimientos
4. Procedimientos recursivos (letrec)

Ahora vamos a introducir el concepto de estado, es decir que las variables pueden cambiar su valor, pero hay un truco, estas realmente no cambian si no que pasan a ser referencias a valores mutables.
